# ThyncSpace backend review — 12 October 2026

## Delivered

Added bounded notebook/tag validation and owner-scoped organization, trash and
history endpoints. Deletion now preserves a tombstone and revokes sharing.
Recovery creates a fresh private note within a transaction; trash restoration
consumes the old entry in that transaction. History stores the prior title/content
atomically with the current content/Yjs state and keeps five prior snapshots.

Added no-store headers to API responses, safe missing-body validation, raster
MIME/base64 validation, strict legacy-board loading, malformed WebSocket URL
handling and isolated validation of live Yjs updates before mutation. Updated
vulnerable dependencies and replaced nodemon with Node's built-in watcher.

## Review passes

1. Reviewed authentication/CSRF routing, note ownership, shared access, persistence,
   serialization, cache use, image admission and dependencies. Fixed gaps in the
   changed paths and added explicit owner filters on library queries.
2. Tested malformed live data and recovery paths. Added validation before Yjs
   applies updates, checked private response projection, and fixed transaction
   return handling for the installed MongoDB driver.
3. Found board savedAt timestamps would consume history slots without content
   changes. Compare validated board content instead; a regression protects the
   retained history. Fixed malformed upgrade targets escaping URL construction.
4. Changed invalid stored-board loading to fail closed instead of opening an
   empty board that a later save could persist. Added a regression.
5. Re-read changed handlers and reran checks after fixes. No additional issue
   was found in the modified paths within this local scope.

## Verification and limits

- npm run check passes lint, types, build and 37 tests.
- New regressions cover organization bounds/operator objects, raster admission,
  invalid live updates without mutation, valid updates, owner query boundaries,
  private response fields, atomic bounded history writes, recovery transaction
  behavior, malformed upgrades, and timestamp-only board stores.
- npm audit: zero known vulnerabilities in all dependency trees.
- Tests use real Yjs/Mongoose types with database method doubles. Docker Desktop's
  daemon was unavailable and no local MongoDB replica set was listening. Real
  transaction rollback, durable restart and concurrent WebSocket recovery against
  MongoDB remain an integration check before deployment.
- Review covers the local application and changes, not cloud IAM, production
  secrets/configuration, backup restoration, external OAuth operation, load/DoS
  capacity, multi-process consistency or a formal security certification.

See README.md for endpoint limits, restore semantics and rollout ordering. No
production data, deployment or remote repository was changed.
